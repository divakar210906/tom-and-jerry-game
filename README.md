# 🐱 Tom and Jerry – 3D Unity Game

A fun 3D game inspired by the iconic Tom and Jerry universe, developed using Unity. Experience an interactive game environment with 3D objects, gameplay mechanics and an engaging visual experience.

## 🎮 Project Overview

This project is a Unity-based 3D game developed as part of a game development practical exercise. It demonstrates the implementation of 3D game environments, game objects, physics components, materials, lighting and interactive gameplay.

## ✨ Features

- 3D game environment
- Interactive game objects
- Character-based gameplay
- Physics and collision interactions
- Materials, textures and lighting
- Real-time gameplay experience

## 🛠️ Technologies Used

- **Game Engine:** Unity
- **Programming Language:** C#
- **Development Environment:** Visual Studio
- **Platform:** Windows

## 🚀 How to Run the Game

1. Open this GitHub repository.
2. Download the project using **Code → Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open the `TomAndJerry` folder.
5. Double-click `TomAndJerryGame.exe`.
6. Enjoy the game!

**Note:** Keep the executable, Data folder and required DLL files together. Do not move or delete individual build files.

## 💻 Running the Source Project

To explore or modify the game:

1. Clone this repository.
2. Open Unity Hub.
3. Add the Unity source project folder.
4. Open it using a compatible Unity Editor version.

*Note: The current repository contains the Windows playable build. The editable Unity source project can be added separately.*

## 🎯 Learning Outcomes

- Understanding the Unity Editor and its workflow.
- Creating and configuring 3D game objects.
- Working with materials, textures and lighting.
- Implementing physics, rigidbodies and colliders.
- Building and exporting a standalone Windows game.
